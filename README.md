# Marco Amantea — Portfolio Cosmic

Nuova versione React/Vite, con welcome dedicata, portfolio filtrabile, tema scuro/chiaro, italiano/inglese, contatti social e playlist casuale.

Avvio: npm install, poi npm run dev.
Build: npm run build. Il risultato è nella cartella dist.

La playlist parte direttamente dal clic su Entra: i 12 brani vengono mescolati senza ripetizioni fino alla fine del ciclo. Il primo brano differisce da quello dell’ingresso precedente. Sono disponibili pausa, successivo, volume e mute. Se il browser blocca la riproduzione, il player invita a riprovare.

Contenuti e collegamenti dei progetti: src/portfolio-data.js.
Contatti, testi e comportamento: src/App.jsx.
Stile e responsive: src/index.css.
Logo e foto: public.

Il progetto originario sul Desktop resta separato da questa nuova versione.
